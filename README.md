# מערכת חתימה דיגיטלית

- `admin.html` – אזור ניהול (בסיסמה): העלאת מסמך, סימון מקומות החתימה/תאריך/שם/טקסט, יצירת קישור ייחודי ושליחה בווצאפ.
- `index.html?r=<id>` – דף החתימה לחותם (מותאם לטלפון).
- `stamp.js` – ציור השדות והחתימה על ה-PDF (pdf-lib), משותף לשני הדפים.
- `Code.gs` – צד השרת ב-Google Apps Script (Sheets + Drive + Gmail). הקוד כאן עם ערכי דוגמה בלבד – הסיסמה ומזהה התיקייה נשמרים רק ב-Apps Script.

הקבצים עצמם (מקור וחתומים) נשמרים בדרייב, לא בריפו.

הגופן `fonts/LiberationSans-Regular.ttf` מופץ תחת רישיון SIL Open Font License.
